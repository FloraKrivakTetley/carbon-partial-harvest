# carbon-partial-harvest
Data and cose associated with LANDIS-II modelling project assessing forest carbon storage and flux under partial harvesting in northern British Columbia.

A publication based on this work is currently under review at Ecological Applications:
Krivak-Tetley, F., C. C. Dymond, E. Lilles, T. Marsden, and B. Eskelson. 2025. Unlocking temperate rainforest carbon sequestration by reducing harvest intensity, 
harvest rate, and residue burning. Ecological Applications In Review.
